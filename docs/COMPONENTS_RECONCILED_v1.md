# Components

Version 0.1, 2026-10-08. Registry and semantic event map required by `DESIGN_STANDARDS.md` (section 1.5, R12). Update this file in the same change as any component work. Components not listed here do not ship.

All token names refer to `tokens.css`. Symbol IDs (`sym.*`) and sound roles are **provisional** until the symbol legend (R4) and `AUDIO.md` exist; they are placeholders for ownership, not designs.

## Rules that apply to every component

1. **Check before building.** Reuse a registered component, extend it with a logged variant (at most five variants), or add a new entry with a stated reason. Two elements with the same purpose and behavior are one component, however they look.
2. **Name by structure and purpose,** never by appearance or screen ("Notice", not "red banner"; "Table", not "portfolio grid").
3. **Semantic elements only.** `button`, `a`, `input`, `select`, `table`, `dialog`, `details` where they fit. A clickable `div` is a defect.
4. **Standard states** (where they apply): default, hover, focus, active, disabled, loading, selected. Disabled always uses `--color-disabled-text`, `--color-disabled-bg` and `--color-disabled-rule`, and exposes its reason as text linked with `aria-describedby`. Focus always uses `--border-focus` in `--color-focus-ring` with `--border-focus-offset`.
5. **Size.** Controls use `--control-size-default` (32px) unless a compact context is registered. On the tablet viewport class, primary controls move up to `--control-size-large`. Nothing interactive is below `--target-min`.
6. **Type roles are used as a triple.** A component asks for a role by name and takes its size, leading and weight together (for example `--type-label-*`). The registry names the size token for brevity. Panels and screens sit on `--space-*` and `--text-*` scales only through these roles and the grid tokens.
7. **Base aliases.** `--color-text-on-action` and the `--ref-*` tier are used only by other tokens, never by components directly.
8. **Action hierarchy.** One primary action per panel or dialog. In every dialog, cancel sits on the left and confirm on the right of one row. Destructive actions look the same everywhere.
9. **No shadows, no gradients.** Overlays separate with `--border-heavy` and `--color-scrim` (`--elevation-none`).
10. **Every colour-coded state has a glyph and a text label** (H3).

## Motion rule

One kind of change, one token. Duration scales by the size of the change.

| Kind of change | Token | Under reduced motion |
|---|---|---|
| Press feedback | `--duration-instant` | unchanged |
| Hover, selection, toggle, value change | `--duration-fast` with `--ease-standard` | instant; opacity change keeps `--duration-fade` |
| Panel, popover, tab, dialog open or close | `--duration-base` with `--ease-standard` (close uses `--ease-exit`) | instant, fade only |
| Turn resolution, map camera move, document reveal | `--duration-slow` with `--ease-standard`; ledger items step by `--duration-stagger` | instant; ledger still reveals item by item without movement |
| Progress | `--ease-linear` | unchanged |

Resolution sequences can always be skipped.

## Semantic event map

One row per event. An implementation uses the whole row: colour role, symbol, motion token and sound role. Sound roles are provisional until `AUDIO.md` is written. "Silence" is a recorded decision, not an omission.

| Event | Color role | Symbol | Motion token | Sound role |
|---|---|---|---|---|
| Select a subject or row | `--color-selected-bg`, `--color-selected-edge` | `sym.selection-frame` | `--duration-fast` | ui-select |
| Hover or preview | `--color-hover-bg` | none | `--duration-fast` | silence (frequent, no information) |
| Keyboard focus | `--color-focus-ring` | none | `--duration-instant` | silence |
| Draft decision added | `--color-info-mark` | `sym.queued` | `--duration-base` | ui-confirm |
| Uncommitted draft removed | `--color-neutral-mark` | `sym.undo` | `--duration-fast` | ui-undo |
| Confirm and commit | `--color-action-primary-bg` | `sym.commit` | `--duration-base` | ui-commit |
| Cancel | `--color-action-secondary-rule` | `sym.cancel` | `--duration-fast` | silence |
| Information notice | `--color-info-mark`, `--color-info-tint` | `sym.info` | `--duration-base` | notice-low |
| Success | `--color-success-mark`, `--color-success-tint` | `sym.success` | `--duration-base` | notice-success |
| Warning | `--color-warning-mark`, `--color-warning-tint` | `sym.warning` | `--duration-base` | notice-warning |
| Critical | `--color-critical-mark`, `--color-critical-tint` | `sym.critical` | `--duration-base` | notice-critical (also announced assertively) |
| Action unavailable or locked | `--color-disabled-text` | `sym.locked` | `--duration-instant` | silence (the reason is shown as text) |
| Turn starts, new brief arrives | `--color-info-mark` | `sym.turn` | `--duration-slow` | turn-start |
| Attention item added | per severity: `--color-warning-mark` or `--color-critical-mark` | `sym.attention` | `--duration-base` | by severity: notice-warning or notice-critical |
| Turn resolution begins | `--color-neutral-mark` | `sym.resolve` | `--duration-slow` | turn-resolve |
| Resolution item revealed | `--color-text-strong` | `sym.change` | `--duration-base`, step `--duration-stagger` | silence (repeats many times per turn) |
| Value changed | `--color-text-strong` | `sym.delta-up`, `sym.delta-down`, `sym.delta-none` | `--duration-fast` | silence |
| Information becomes stale or unknown | `--color-fog-stroke` | `sym.fog-stale` | `--duration-fade` | silence (announced in the live region) |
| Intelligence improves (estimate becomes known) | `--color-info-mark` | `sym.revealed` | `--duration-base` | notice-low |
| Save succeeded | `--color-success-mark` | `sym.saved` | `--duration-fade` | silence |
| Save or load failed | `--color-critical-mark` | `sym.save-failed` | `--duration-base` | notice-critical |
| Act transition | `--color-neutral-mark` | `sym.act` | `--duration-slow` | act-transition |
| Session ends (fragile success, partial failure, other end states) | `--color-neutral-mark` | `sym.end` | `--duration-slow` | end-state |


## Reconciliation notice (2026-10-08)

`Commit action` submits a consequential command immediately and irreversibly (except future separate remedial commands). The draft tray is optional/non-authoritative, and the decision journal is immutable. The five candidate indicators are suspended from permanent UI until verified methodology and disclosure policy exist. See `AFRICAN_MANDATE_SPEC_RECONCILIATION_v1.md`.
